# 당근 구인 자동화 앱 (강쌤과외)

강쌤과외 운영폰(갤럭시 S22)에 까는 안드로이드 앱이에요. 당근알바에 올린 선생님 구인 공고로 들어온 지원을 알아채 기록하고, 지원자에게 당근 첫 메시지 → 휴대폰 번호 받기 → 문자로 이어 가기를 앱이 맡도록 만드는 중이에요. 티켓 KSS-284.

> 지원자 이름·번호·대화는 폰 안 DB에만 둬요. 이 리포와 프로젝트 문서에는 올리지 않아요.

## 지금 되는 것 (2026-10-20)

| 기능 (사용자 프로세스) | 하는 일 | 상태 |
|---|---|---|
| 지원 감지 (B1) | 당근 알림으로 새 지원을 '새 지원'으로 기록하고 공고에 붙임 | 동작 |
| 당근 가져오기 (C) | 버튼을 누르면 당근 화면을 옮겨 다니며 공고·지원자·대화를 읽어 앱 기록을 맞춤 (읽기만) | 동작 |
| 다음에 앱이 할 일 (B2~) | 지원자마다 무엇을·언제·어떤 문구로 보낼지 보여 줌 (보내지 않음) | 동작 |
| 첫 메시지 드라이런 (개발용) | 지원자 채팅방까지 가서 보낼 문구만 확인 (입력·전송 없음) | 동작 — 10/20 채팅 전인 새 지원자 길을 더함 |
| 실제 발송 시험 (개발용) | 테스트 폰 지원자 한 명에게만 첫 메시지 → 번호 받기 → 마무리 | 만듦, 폰 시험 전 |
| 공고 게시 (A) | 상시 공고·회차·마감을 앱 안에 기록 (당근에 올리지 않음) | 기록만 |
| 문자 응대 (B4~) | — | 아직 없음 |

실제 지원자에게 자동으로 보내는 운영은 아직 없어요. 담당자 확인 뒤에 켜요 (담당자 확인사항 29).

## 폴더

```
app/src/main/java/com/kangsam/daangnrecruit/
├─ (맨 위)  DB, 당근 알림 받기, 접근성(당근 화면을 읽고 누르는 손), 지원자 줄 바꾸기·확인 탭 버튼 같은 공통 규칙
├─ sync/    C. 당근 가져오기 — 당근 화면 읽기·옮겨 다니기 → 앱 기록에 맞춤
├─ reply/   B. 지원자 응대 — 문구·검사·계획, 첫 메시지 드라이런, 실제 발송 시험
└─ ui/      화면 (Jetpack Compose) — 아래 탭 5개와 그 안의 화면
app/src/main/res/   글꼴(IBM Plex Sans KR), 접근성 설정, 앱 아이콘
CODE_MAP.md         파일마다 하는 일과 지키는 것
```

기능 폴더(`sync/` · `reply/` · `ui/`)마다 README가 있어요. 그 기능이 어떤 순서로 돌고, 고칠 때 어디를 보는지 적어 뒀어요. 파일 하나하나가 하는 일은 `CODE_MAP.md`에 있어요.

## 빌드·설치

1. Android Studio로 이 폴더를 열어요. Gradle이 필요한 것을 알아서 받아요 (Gradle 9.6, JDK 25 — `gradle/gradle-daemon-jvm.properties`).
2. 운영폰을 USB로 연결하고, 위쪽 기기 목록에서 폰을 고른 뒤 실행(▶)을 눌러요. 이미 깔려 있으면 다시 실행(↻)을 눌러요.
3. **다시 깔 때마다 폰의 접근성 '당근 화면 읽기 (Kangsam)'이 꺼져요.** 설정 → 접근성 → 설치된 앱에서 다시 켜요.

| | 값 |
|---|---|
| 패키지 | `com.kangsam.daangnrecruit` (앱 이름 Kangsam Daangn Recruit) |
| 안드로이드 | minSdk 26 · targetSdk 37 |
| 언어·라이브러리 | Kotlin 2.2.10 · AGP 9.4.1 · Compose BOM 2026.02.01 (Material3) · Room 2.8.5 (KSP) |
| DB | 폰 안 `recruit.db` (표 구조 버전 4). 업데이트 뒤 처음 열기 전과 하루 한 번 폰 안 사본 (`files/db_backup`, 최근 7개) |

## 폰에서 켜야 하는 것 (처음 한 번)

1. **알림 접근** — 당근 알림(지원·채팅)을 읽어요. 설정 탭 맨 아래 '알림 기록 (개발용)'에 지금 상태와 '알림 접근 설정 열기' 버튼이 있어요.
2. **접근성 '당근 화면 읽기 (Kangsam)'** — 당근 화면을 읽고 누를 때 써요 (가져오기·드라이런·실제 발송 시험).
3. **앱 알림** — 안드로이드 13부터 첫 화면에서 한 번 물어요. 전체 멈춤·닉네임이 다른 계정 같은 일을 알려요.
4. **당근 앱 알림** — 당근 앱 알림과 '당근알바' 채팅방 알림이 켜져 있어야 지원 알림이 와요 (담당자 확인사항 28).
5. 앱이 당근을 다루는 동안 폰 화면이 켜져 있고 잠금이 풀려 있어야 해요.

## 기능 켜기·끄기

설정과 각 탭의 스위치로 켜고 꺼요: 전체 멈춤 · 당근 가져오기 · 당근 응대 · 문자 응대 · 자동 게시 (`FeatureSettings.kt`). 전체 멈춤이 켜져 있으면 앱은 아무것도 하지 않아요. 당근 화면에 보안 인증·이용 제한 글자가 보이면 앱이 스스로 전체 멈춤을 켜요.

## 지키는 것

- 지원자 이름·번호·대화는 폰 안 DB에만 둬요. 앱이 본 화면(`files/debug`)이나 DB 사본을 맥으로 꺼낼 땐 git이 무시하는 `build/` 아래에만 둬요.
- 실제 지원자에게 보내는 기능은 담당자 확인 전엔 만들거나 켜지 않아요. 지금 실제로 보내는 건 실제 발송 시험(테스트 폰 지원자)뿐이고, 시험이 끝나면 '끔'으로 둬요.
- 당근에서는 정해진 칸만 눌러요 (`sync/DaangnNav.kt` · `reply/LiveNav.kt`). 글쓰기·마감·수정·근무확정·당근페이 같은 칸은 누르지 않아요.
- DB 표를 바꿀 땐 기록을 지우지 않고 옮겨요 (`Migrations.kt`, 표 구조 버전 +1).
- 나머지는 `CODE_MAP.md`의 '지키는 것'에 있어요.

## 시험

판단하는 코드(문구·검사·화면 읽기·길 찾기·기록 맞추기)는 안드로이드 없이 도는 순수 코드라서 폰 없이 시험해요. 덤프 모양을 줄인 가짜 당근 화면과 메모리 DB를 써요 (10/20 기준 436개). 이 시험 틀은 아직 리포 밖에 있어요 (맥 `build/claude_tmp/impl_1020/harness`). `app/src/test`·`app/src/androidTest`의 Example 파일은 Android Studio가 만든 그대로예요.
